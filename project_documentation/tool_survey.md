## Decision Gate (Resolved)

- [x] **Selected Architecture (Hybrid Reuse + Deterministic R Module):**
  1. **gRNA Discovery & Scoring Engine:** Reuse **Bioconductor R packages (`crisprDesign` + `crisprScore` + `crisprBowtie` / `CRISPRseek`)** as the primary R-native engine, with **FlashFry CLI** or pure-R Rule Set 2 + CFD/MIT scoring + `Biostrings::vcountPDict` / `Rbowtie` as a zero-Python fallback so the bundled Electron `.app` remains self-contained like `HCR Probe Designer.app`.
  2. **Genomic Context & Isoform Prioritization:** Reuse the GTF parsing and shared-CDS/isoform track architecture from `HCR_probe_design_v41.R`, prioritizing **5′ UTR / promoter** and **early shared coding exons (5′ CDS)** to disrupt protein coding sequence.
  3. **Homology-Arm Designer:** Build a dedicated, unit-tested R module using `Biostrings` / `Rsamtools` that takes the selected target's strand and PAM coordinates, computes the exact SpCas9 blunt cut site (**3 bp upstream / 5′ of the first PAM nucleotide on the target strand**), extracts user-adjustable **1–2 kb homology arms** on either side, checks for internal PAM/protospacer re-cleavage sites, low-complexity/`N` regions, and chromosome bounds, and exports FASTA + CSV + reproducibility log.
